# Improve Olivia’s four-page PDF for printing

The current Canva PDF is 11.25 × 14.06 inches per page. Its text is embedded and remains sharp, but the photo-grid images are mostly about 132–188 pixels per inch at print size, and a prominent image on the information pages is about 96 pixels per inch. “4K” is a screen measure; at this page size, print quality depends on the original image detail and the printer’s output settings. Enlarging the PDF alone cannot recreate detail that is missing from those photos.

## Deliverable
- Make a separate, print-optimized copy of the four-page English/French PDF at its existing physical page size, preserving the layout, wording, and original file.
- Carefully improve the embedded photos with modest noise reduction, upscaling, and print-oriented sharpening, avoiding invented facial details or changes to Olivia’s appearance. Keep the existing sharp text and graphic elements intact rather than flattening entire pages into images.
- Visually inspect all four output pages against the original for artifacts, text changes, clipping, and page alignment; provide the improved PDF together with candid guidance on what remains limited by the source images.

## Technical approach
- Process the embedded photographic images separately from fonts and vector artwork, then place improved images back into a copy of the PDF while retaining its dimensions and selectable text where feasible.
- Render and compare every page at print inspection size. Confirm the final PDF’s page count, dimensions, embedded fonts, and effective image resolution. If safe image replacement is not possible without damaging layout or text, use the original PDF and report that limitation rather than deliver a degraded reconstruction.
